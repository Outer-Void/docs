# Outer-Void Documentation Repository

Central engineering, governance, legal and policy documentation for the Outer-Void ecosystem.

## Ecosystem (engineering and governance)

- [ecosystem/README.md](ecosystem/README.md): the ecosystem map, authority boundaries, when to use `blux`
  and when to use `ax`, BLHermes disposition, product maturity, the evidence model and the status
  vocabulary.
- [ecosystem/status-matrix.md](ecosystem/status-matrix.md): per-component status across standalone, BLUX,
  ax, tests, hardware, security, packaging, distribution and release. It is generated by
  `python3 tools/build_status_matrix.py`; `--check` validates it.
- [ecosystem/findings.md](ecosystem/findings.md): implementation gaps found by documentation passes.
